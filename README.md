# Netflix Clone 🎬

A simple **Netflix-inspired website** built using **HTML and CSS**. This project focuses on frontend layout, styling, and responsive design.

---

## 📁 Project Structure

```
Netflix/
│
├── assets/
│   ├── images/        # All image assets
│   └── videos/        # Video files (trailers/backgrounds)
│
├── favicon.ico        # Website favicon
├── index.html         # Main HTML file
├── style.css          # CSS styling file
└── README.md          # Project documentation
```

---

## ✨ Features

* Netflix-style UI design
* Responsive layout for desktop and mobile
* Clean and modern CSS styling
* Organized assets (images & videos)
* Beginner-friendly project structure

---

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

---

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open the project folder
3. Double-click `index.html`
4. View the project in your browser
